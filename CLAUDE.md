Test automation project using Playwright.

## Testing

When writing manual test cases or any automated tests, apply ISTQB-defined test design techniques to ensure systematic, well-reasoned coverage rather than arbitrary test cases. Depending on what's being tested, use techniques such as:

- Equivalence partitioning
- Boundary value analysis
- Decision table testing
- State transition testing
- Use case / scenario testing
- Exploratory testing (where scripted techniques don't fit)
